# Пользовательские истории — «Домашняя бухгалтерия»

## Роли (Personas)
- **Член семьи (User)** — вносит доходы и расходы, смотрит баланс и отчёты.
- **Владелец бюджета (Admin)** — настраивает категории и лимиты на месяц.

---

## Модуль 1. Управление транзакциями (Transactions Module)

### US-1.1 Добавление операции
**Как** член семьи, **я хочу** добавить операцию (сумма, категория, дата,
тип «доход/расход», комментарий), **чтобы** вести точный учёт бюджета.
- *Критерии приёмки:*
  - [ ] Операция сохраняется со всеми полями; дата по умолчанию — сегодня.
  - [ ] Тип операции выбирается из двух значений: income / expense.
  - [ ] Сумма не может быть отрицательной или пустой.

### US-1.2 Редактирование операции
**Как** член семьи, **я хочу** изменить любую ранее созданную операцию,
**чтобы** исправить ошибку ввода.
- *Критерии приёмки:*
  - [ ] Поля редактируются по отдельности или все сразу.
  - [ ] После сохранения аналитика пересчитывается.

### US-1.3 Удаление операции
**Как** член семьи, **я хочу** удалить ошибочную операцию, **чтобы**
история отражала реальные траты.
- *Критерии приёмки:*
  - [ ] Перед удалением запрашивается подтверждение.
  - [ ] Удалённая операция исчезает из всех отчётов.

---

## Модуль 2. Категории и Бюджеты (Budget Module)

### US-2.1 Список категорий
**Как** владелец бюджета, **я хочу** видеть и пополнять список категорий
(еда, подписки, транспорт и т. д.), **чтобы** группировать операции.
- *Критерии приёмки:*
  - [ ] Категории предустановлены, их можно добавлять и переименовывать.
  - [ ] Название категории уникально.

### US-2.2 Лимит на категорию в месяц
**Как** владелец бюджета, **я хочу** задать месячный лимит трат для каждой
категории, **чтобы** контролировать перерасход.
- *Критерии приёмки:*
  - [ ] Лимит задаётся числом >= 0 на календарный месяц.
  - [ ] Приложение показывает статус: «Превышен лимит» / «Осталось N руб.».

### US-2.3 Предупреждение о превышении
**Как** член семьи, **я хочу** видеть предупреждение при превышении лимита,
**чтобы** вовремя скорректировать траты.
- *Критерии приёмки:*
  - [ ] Предупреждение появляется сразу после операции, выводящей сумму за лимит.

---

## Модуль 3. Аналитика и Отчеты (Analytics Module)

### US-3.1 Общий баланс
**Как** член семьи, **я хочу** видеть общий баланс (доходы минус расходы),
**чтобы** понимать текущее финансовое состояние.

### US-3.2 Расходы за период
**Как** член семьи, **я хочу** получить сумму расходов за выбранный период
(дата «с» — «по»), **чтобы** анализировать траты.

### US-3.3 Топ-3 затратных категорий
**Как** член семьи, **я хочу** видеть топ-3 самых затратных категории за
период, **чтобы** понять, на что уходит больше всего.

---

## Модуль 4. Хранение данных и Экспорт (Data Storage Module)

### US-4.1 Сохранение при выходе
**Как** пользователь, **я хочу**, чтобы все операции и лимиты сохранялись
в файл (JSON), **чтобы** не терять данные между запусками.

### US-4.2 Загрузка при старте
**Как** пользователь, **я хочу**, чтобы при запуске приложение загружало
историю операций и настройки бюджетов, **чтобы** продолжить работу с того же места.

### US-4.3 Экспорт истории
**Как** пользователь, **я хочу** экспортировать историю операций в CSV,
**чтобы** передать данные или сделать резервную копию.

Консольное приложение для совместного и личного учёта доходов, расходов и контроля семейного бюджета без лишней суеты.

Модули
Transactions Module — добавление, редактирование и удаление операций (классы Transaction, TransactionService).
Budget Module — список категорий, месячные лимиты и проверка превышения (классы Category, BudgetManager).
Analytics Module — общий баланс, расходы за период, топ-3 самых затратных категорий (классы AnalyticsService, FinancialReport).
Data Storage Module — сохранение истории операций и настроек бюджета в JSON и загрузка при запуске (классы DataRepository, FileStorage).
